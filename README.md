## Étendue complète

EGA I (chapitre 0 compris), EGA II, EGA III-1, EGA III-2 et EGA IV-1 à IV-4.

Le français imprimé est conservé diplomatiquement. Les réparations de fidélité, les errata publiés et les défauts mathématiques vérifiés sont consignés explicitement dans la provenance.

Le PDF cumulatif comporte **1,245 pages physiques** : une couverture éditoriale, puis le corps complet de l’édition. Il pèse 12,938,033 octets ; SHA-256 `9C2B48B178446C4922E0E7B3DEAB52B60A0A972CEEA102987ECB351A15167EFD`. Les huit étiquettes de fascicules sur la couverture sont des liens internes vers leurs ouvertures exactes. Cette révision r7 supprime une ancienne note de pilote non composée qui décrivait à tort EGA III-1 comme encore ouvert ; le texte diplomatique et les PDF restent identiques à r6.

## Contenu vérifiable

Le dépôt lie 189 fichiers sources éditables (14,389,387 octets), arbre SHA-256 `1BD7DC0347DA3B20F48F37636939892C4B068C25CBAD85C8804969BE4317248F`. La release fournit aussi le lecteur autonome d’EGA IV-4, une provenance aplatie et nettoyée des chemins privés, ainsi que les sommes SHA-256.

Les lecteurs français et anglais restent indépendants : aucun document bilingue, parallèle, juxtaposé ou intercalé n’est produit. Aucun agrément des auteurs, de l’IHÉS, de NUMDAM ou d’un mainteneur Stacks n’est revendiqué. Contribution au projet : `AI typesetting & translation`.
