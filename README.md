# Éléments de géométrie algébrique (EGA) — Édition française diplomatique cumulative complète

[Lire l’édition cumulative complète](https://github.com/KokunoYumeto/ega-fr/releases/download/ega-fr-2026-09-08-r12/EGA_French_Cumulative_Reader.pdf)

<p>Édition française d’<em>Éléments de géométrie algébrique</em>, d’Alexander Grothendieck et Jean Dieudonné. Le lecteur cumulatif réunit EGA I, chapitre 0 compris, EGA II, EGA III-1 et III-2, puis EGA IV-1 à IV-4.</p><p>Cette édition diplomatique conserve les formulations, les notations et les erreurs présentes dans les textes imprimés. Les erreurs de transcription sont corrigées d’après les témoins imprimés ; les errata et les décisions éditoriales sont documentés séparément. Le dossier comprend le lecteur cumulatif, les lecteurs autonomes disponibles, les sources TeX modifiables, les documents de provenance et les sommes de contrôle.</p><p>Commencez par <strong>EGA_French_Cumulative_Reader.pdf</strong> pour lire l’ensemble de l’édition. Les <a href="https://github.com/KokunoYumeto/ega-fr">sources et publications françaises</a> sont également disponibles sur GitHub.</p><p>Pour la traduction anglaise, consultez l’<a href="https://doi.org/10.5281/zenodo.21921591">édition anglaise distincte</a> et son <a href="https://github.com/KokunoYumeto/ega-en">dépôt GitHub</a>. Les éditions française et anglaise restent séparées.</p>
