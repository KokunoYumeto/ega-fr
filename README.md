# Éléments de géométrie algébrique (EGA) — édition française diplomatique cumulative

[Lire ou télécharger le lecteur cumulatif complet](https://github.com/KokunoYumeto/ega-fr/releases/download/ega-fr-2026-09-05-r11/EGA_French_Cumulative_Reader.pdf)

- DOI conceptuel stable : <https://doi.org/10.5281/zenodo.21921588>
- Publication courante : `ega-fr-2026-09-05-r11`

## Étendue

EGA I (chapitre 0 compris), EGA II, EGA III-1, EGA III-2 et EGA IV-1 à IV-4.

Le texte français imprimé est conservé diplomatiquement. Les réparations de
fidélité, les errata publiés, les défauts mathématiques vérifiés, les décisions
typographiques et leurs inverses exacts sont consignés dans la provenance.

Le lecteur cumulatif comporte 1,245 pages physiques. L’archive des sources
contient exactement les 63 fichiers `.tex`/`.bib` actifs dans les
lecteurs français courants; elle exclut les témoins anglais dormants. L’archive
de provenance publie une projection sans chemins privés de 3,678
dossiers de décision, de contrôle et de validation.

Les éditions française et anglaise restent indépendantes : aucun document
bilingue, parallèle, juxtaposé ou intercalé n’est produit. Aucun agrément des
auteurs, de l’IHÉS, de NUMDAM ou d’un mainteneur Stacks n’est revendiqué.
Contribution au projet : `AI typesetting & translation`.
