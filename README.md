## Étendue complète

EGA I (chapitre 0 compris), EGA II, EGA III-1, EGA III-2 et EGA IV-1 à IV-4.

Le français imprimé est conservé diplomatiquement. Les réparations de fidélité, les errata publiés et les défauts mathématiques vérifiés sont consignés explicitement dans la provenance.

Le PDF cumulatif comporte **1 245 pages physiques** : une couverture éditoriale, puis le corps complet de l’édition. Il pèse 13 122 807 octets ; SHA-256 `3CF7B57D709E4BFC7933A1C581FD55A7270773A7CF310B2211D7942557C8C96B`. Les huit étiquettes de fascicules sur la couverture sont des liens internes vers leurs ouvertures exactes.

La révision r9 reconstruit le lecteur cumulatif à partir de l’arbre français courant lié à la file Canon R30. Le lecteur autonome d’EGA IV-4 est conservé octet pour octet depuis r8.
