# Édition française du 8 septembre 2026

Cette édition actualise le lecteur cumulatif à partir des transcriptions françaises validées. Elle réunit EGA I, chapitre 0 compris, EGA II, EGA III-1 et III-2, puis EGA IV-1 à IV-4.

Le texte français reste diplomatique : les erreurs de transcription sont corrigées d'après les imprimés, tandis que les erreurs présentes dans les imprimés et les décisions éditoriales sont documentées séparément. Les quatre lecteurs autonomes d'EGA IV sont repris sans modification.

Les sources TeX modifiables correspondent aux fichiers effectivement employés par les lecteurs. Les documents de provenance décrivent leurs témoins, les interventions éditoriales et les contrôles de cette édition.
